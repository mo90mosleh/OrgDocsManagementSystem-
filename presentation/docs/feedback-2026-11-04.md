## Access and storage

Public presentation: `https://mo90mosleh.github.io/OrgDocsManagementSystem-demo/`. Public read-only organization/process/KPI data comes from the dedicated Supabase project; **no write capability is embedded**. Profiles of public processes are readable. Personal names/contact data and assignment records are not exposed to anonymous Data API clients.

Private management: `https://orgdocs-demo.mo90mosleh.chatgpt.site/admin`. It uses the existing Sites sign-in/access list; only the configured verified owner email receives ADMIN and mutations. This is not a simulated role switch or a shared default password. Additional authorized visitors, if granted platform access, are viewers. Full internal account management and process-specific edit grants are not introduced here.

Business data persists in PostgreSQL. Browser feedback retains its existing localStorage key and JSON format. The supplied feedback file is not automatically imported or marked done in a user's browser. No imported Rassan workflow list or additional business fixtures were added.
