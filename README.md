# نما — ارائه عمومی راسان

۴۴ فرآیند، ۴۴ شناسنامه، ۴۴ شاخص و ۹۰ ارجاع سند از بستهٔ بازنگری ۰٫۱ (۲۰۲۶-۱۱-۰۴). پیشنهادها پیش‌نویس هستند. انتشار داده‌ها و لینک‌ها با دستور صریح مالک انجام شده است.

دادهٔ زنده از Supabase خوانده می‌شود و در قطع اتصال، نسخهٔ ذخیره‌شده برای مشاهده باقی می‌ماند. Render لازم نیست. بازدید عمومی بدون ورود است. ورود مدیریتی با ایمیل/رمز Supabase انجام می‌شود؛ مدیر تأییدشده می‌تواند ساختار سازمان، شناسنامه‌ها و برند را در دیتابیس ذخیره کند. در قطع اتصال، نسخهٔ ذخیره‌شده با پیام مشخص و بدون ویرایش نمایش داده می‌شود. بازخوردها در مرورگر ذخیره و به JSON صادر می‌شوند.
