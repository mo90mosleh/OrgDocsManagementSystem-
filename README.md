# نما — ارائه عمومی راسان

۴۴ فرآیند، ۴۴ شناسنامه، ۴۴ شاخص و ۹۰ ارجاع سند از بستهٔ بازنگری ۰٫۱ (۲۰۲۶-۱۱-۰۴). پیشنهادها پیش‌نویس هستند. انتشار داده‌ها و لینک‌ها با دستور صریح مالک انجام شده است.

نمایش اطلاعات از فایل نسخه‌بندی‌شدهٔ همین مخزن است و به Render یا Supabase وابسته نیست. ویرایش پایگاه داده در این نسخه ارائه نمی‌شود. بازخوردها در مرورگر ذخیره و به JSON صادر می‌شوند.
